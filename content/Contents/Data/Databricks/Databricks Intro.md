
### What is Databricks?
Databricks is a multi-cloud lakehouse platform based on apache spark. 

### What is a Data Lakehouse?
A lakehouse is a hybrid between a data lake and a data warehouse, combining the flexibility of a lakehouse with the structure and reliability of a data warehouse. 

### What is a Platform?
A platform is a type of architecture where the control panel where all the administrative tasks are done like orchestration and the executor where all of the computation takes place exist as separate apps. But are presented as one vie the interface. 

### Spark on Databricks
- In-memory, distributed data processing. 
- All languages support:
	- Scala, Python, SQL, R & Java.
- Batch processing & stream processing.
- Structured, semi structured and unstructured data.

### Databricks File System (DBFS)
- Distributed file system.
- Preinstalled in Databricks clusters.
- Abstraction layer:
	- data persisted to the underlaying cloud storage.
